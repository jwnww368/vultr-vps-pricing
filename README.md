## 가격표 뒤에 있는 비용

어느 제공사든 월 요금만으로 총비용이 끝나지는 않는다. Vultr에서 미리 확인해둘 항목은 다음과 같다.

- **자동 백업은 유료 애드온**이다. 인스턴스 요금의 20%가 추가된다. $5 플랜이면 월 $1. 백업이 기본 포함인 Hostinger와 비교하면 불리한 부분이지만, 대신 스냅샷을 직접 찍어두는 방식으로 대체할 수도 있다.
- **트래픽 초과분은 GB 단위로 추가 과금**된다. Cloudzy처럼 속도만 제한하는 방식과 다르니, 트래픽이 튀는 서비스라면 플랜을 한 단계 올리는 편이 안전하다.
- **DDoS 전용 보호는 별도 유료 애드온**이다. JustHost처럼 기본 포함을 내세우는 제공사와 비교되는 지점이다.
- **Windows는 라이선스 요금이 별도**다. Linux 계열(Ubuntu, Debian, Rocky, AlmaLinux, FreeBSD 등)은 추가 비용 없이 선택할 수 있다.
- 반대로 **전용 IPv4는 기본 포함**이다. IPv4를 월 199₽에 파는 JustHost 방식과 비교하면 초기 셋업 비용이 단순하다.

> 예산이 빡빡한 개인 프로젝트라면, 자동 백업을 끄고 중요한 데이터만 주기적으로 스냅샷으로 관리하는 조합이 실사용 비용을 낮추는 방법이다.

## Vultr에서 서버 배포하는 절차

저렴한 VPS를 처음 써보는 사람 기준으로 과정을 정리하면 다섯 단계다.

1. 회원가입 후 결제 수단을 등록한다. 카드 외에 PayPal 등을 지원한다.
2. 제품 선택에서 Cloud Compute를 고르고, Regular 또는 High Performance 중 하나를 고른다.
3. 리전을 선택한다. 한국 사용자 대상이라면 서울을, 글로벌 서비스라면 사용자가 몰리는 지역을 고른다.
4. OS 이미지를 고른다. Ubuntu 같은 리눅스 배포판 외에 Marketplace 앱(워드프레스, Docker 등)으로 바로 배포할 수도 있고, 직접 만든 ISO를 업로드해서 설치하는 것도 가능하다.
5. 플랜 크기를 정하고 배포하면, 루트 접근 정보가 발급되고 SSH로 바로 접속할 수 있다.

배포 자체는 보통 1분 내외로 끝난다. 이후에는 방화벽 규칙을 Vultr 패널에서 무료로 설정할 수 있으니, 서버를 띄운 직후 SSH 포트 정도는 먼저 정리해두는 게 좋다.

## 자주 묻는 질문

### 512MB RAM으로도 워드프레스를 돌릴 수 있나요?

기술적으로는 가능하지만 권장하지 않는다. 워드프레스와 MySQL을 같이 띄우면 512MB는 여유가 없어서, 트래픽이 조금만 몰려도 스왑으로 버티는 상태가 된다. 워드프레스가 목적이라면 $5(1GB) Regular 또는 $6 High Performance가 현실적인 최소선이다. 512MB는 업타임 모니터나 단순 봇처럼 메모리를 거의 안 쓰는 작업에 맞는 크기다.

### 트래픽을 초과하면 어떻게 되나요?

Vultr는 초과분을 GB 단위로 청구한다. 같은 저가 VPS 시장이라도 정책은 제각각이라서, Cloudzy는 초과 시 속도를 제한하고 IONOS와 JustHost는 트래픽 자체를 무제한으로 풀어준다. 본인 서비스의 월 아웃바운드 트래픽을 예상해보고, 크게 넘을 것 같다면 무제한 트래픽 제공사를 먼저 고려하는 편이 요금 계산에 안전하다.

### Vultr에 환불 보장 기간이 있나요?

Vultr는 Cloudzy(14일)나 Hostinger(30일)처럼 홈페이지에서 명시적으로 내세우는 환불 보장 기간은 없다. 대신 애초에 시간 단위 과금이라, "며칠만 써보고 싶다"는 니즈는 환불 정책 없이도 해결된다. 서버를 지우기 전까지 발생한 사용량만 내면 되기 때문이다. 상시 운영용으로 넘어갈 때는 그 시점에 플랜과 용도를 확정하는 흐름으로 가면 된다.

### 서울 리전이 실제로 의미가 있나요?

한국 방문자를 대상으로 하는 웹사이트나 API라면 의미가 크다. 동남아나 미국 리전을 쓸 때와 비교하면 응답 지연이 체감 수준으로 달라진다. 개인 봇이나 학습용 서버처럼 사용자가 본인 하나뿐이라면 리전 선택이 크게 중요하지 않다.
